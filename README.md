# Лабораторна робота №14

Next.js (App Router): маршрути, серверні та клієнтські компоненти, оптимізація шрифтів і зображень. Проєкт The Wild Oasis.

## Запуск

```bash
npm install
npm run dev
```

## Збірка

```bash
npm run build
npm start
```

## Що зроблено

- Маршрути: `/`, `/about`, `/cabins`, `/account`, `/users`.
- Компоненти в `app/_components` (папка з `_` не стає маршрутом): `Header`, `Logo`, `Navigation`, `CabinCard`, `Counter`.
- Tailwind CSS 4 (`postcss.config.mjs`), власні кольори `primary` та `accent` через `@theme` у `app/_styles/globals.css`.
- Шрифт Josefin Sans через `next/font/google`.
- `metadata` з шаблоном заголовка `%s / The Wild Oasis` на кожній сторінці.
- `next/image` (`Image`) для логотипа, фону головної та картинок на сторінці About (статичний імпорт, `placeholder="blur"`).
- `next/link` (`Link`) для навігації.
- `app/loading.js`: глобальний лоадер.
- Сторінка `/users`: серверний компонент завантажує користувачів з jsonplaceholder і передає їх у клієнтський `Counter` через props.
- `app/_lib/data-service.js` перенесено в проєкт (підключення до бази буде в ЛР 15).

## Дослідження: розмір зображення залежно від quality

Фон головної сторінки (`bg.png`) виводиться через компонент `Image`. Next.js сам стискає картинку і віддає її у форматі WebP. Розмір перевірявся у DevTools (вкладка Network, фільтр Img) для ширини 1920.

| Що завантажується | Розмір |
|---|---|
| Оригінальний `bg.png` | близько 7,2 МБ |
| `quality=75` (WebP) | близько 45 КБ |
| `quality=80` (WebP) | близько 56 КБ |

Висновок: чим вище `quality`, тим більший файл, тому при 80 він приблизно на чверть більший, ніж при 75. Нижче значення зменшує розмір і прискорює завантаження, але погіршує якість зображення. Завдяки `Image` користувач завантажує десятки кілобайт замість кількох мегабайт. У `next.config.mjs` дозволені значення якості задаються в `images.qualities`.
